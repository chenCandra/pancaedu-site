## 🌱 Apersepsi

Kenapa seruling dan tuba menghasilkan nada yang jauh berbeda meski cara memainkannya mirip (meniup kolom udara)? Dan kenapa saat dua gitar dipetik bersamaan dengan nada yang HAMPIR sama, kadang terdengar bunyi "wow-wow-wow" yang aneh?

## 🤔 Coba Pikirkan

Menurutmu, apa yang menentukan tinggi-rendahnya nada yang dihasilkan sebuah kolom udara (seperti pada alat musik tiup)? Panjang kolomnya? Atau hal lain?

## 🔎 Eksplorasi Konsep

### Resonansi

<div class="mtr-def">
🎵 <strong>Resonansi</strong> adalah penguatan getaran/bunyi yang terjadi ketika frekuensi getaran suatu sumber SAMA dengan frekuensi alami sistem lain -- sistem itu jadi ikut bergetar dengan amplitudo besar.
</div>

### Pipa Organa

<div class="mtr-formula-utama">
  <div class="mtr-formula-card">
    <div class="mtr-formula-rumus">Pipa Terbuka: λ = 2L</div>
    <div class="mtr-formula-rumus">Pipa Tertutup: λ = 4L</div>
  </div>
  <p class="mtr-formula-keterangan-judul">Keterangan:</p>
  <ul class="mtr-formula-keterangan">
    <li><strong>λ</strong> = panjang gelombang nada dasar (m)</li>
    <li><strong>L</strong> = panjang kolom udara/pipa (m)</li>
    <li>Pipa terbuka (nada dasar): L = λ/2. Pipa tertutup (nada dasar): L = λ/4.</li>
  </ul>
</div>

Lalu frekuensinya dihitung dengan **f = v/λ** seperti biasa.

<div class="mtr-note">
⚠️ <strong>Hati-hati miskonsepsi:</strong> <del>Pipa organa terbuka dan tertutup dengan panjang sama menghasilkan nada yang sama</del>. Yang benar: keduanya menghasilkan λ (dan f) yang BERBEDA, karena pola gelombang berdiri yang terbentuk berbeda -- ujung tertutup memaksa adanya simpul di sana, ujung terbuka memaksa adanya perut.
</div>

### Pelayangan Bunyi (Beat)

<div class="mtr-formula-utama">
  <div class="mtr-formula-card">
    <div class="mtr-formula-rumus">fb = |f1 − f2|</div>
  </div>
  <p class="mtr-formula-keterangan-judul">Keterangan:</p>
  <ul class="mtr-formula-keterangan">
    <li><strong>fb</strong> = frekuensi pelayangan (Hz)</li>
    <li><strong>f1, f2</strong> = frekuensi dua sumber bunyi (Hz)</li>
    <li>Makin dekat f1 dan f2, makin kecil (lambat) pelayangan yang terdengar -- dipakai musisi untuk menyetem alat musik.</li>
  </ul>
</div>

Ketika dua gelombang bunyi berfrekuensi HAMPIR SAMA berinterferensi, hasilnya adalah bunyi yang kuat-lemahnya berubah secara periodik -- fenomena inilah yang dimanfaatkan musisi untuk menyetem alat musik. Coba perhatikan dua gitar yang dipetik bersamaan dengan nada yang hampir (tapi belum persis) sama -- akan terdengar bunyi "wow-wow-wow" yang berdenyut, bukan bunyi yang stabil.

Coba lihat sendiri bagaimana dua gelombang membentuk pola "berdenyut" itu -- geser kedua frekuensinya, lalu amati gelombang jumlahnya (yang tebal di bawah):

  <p class="mtr-mini-caption">🎧 Geser frekuensi gelombang 1 dan 2 -- perhatikan gelombang jumlahnya (tebal, di bawah) yang "menggembung-mengecil" secara berkala:</p>

(function () {
  var canvas = document.getElementById('beatCanvas');
  if (!canvas) return;
  var ctx = canvas.getContext('2d');
  var f1Slider = document.getElementById('beatF1Slider');
  var f2Slider = document.getElementById('beatF2Slider');
  var f1Label = document.getElementById('beatF1Label');
  var f2Label = document.getElementById('beatF2Label');
  var fbLabel = document.getElementById('beatFbLabel');
  var w = canvas.width, h = canvas.height;
  var atasY = h * 0.27;
  var bawahY = h * 0.72;
  var ampAtas = h * 0.16;
  var ampBawah = h * 0.2;
  var waktuMulai = performance.now();
  function gambarGaris(y) {
    ctx.strokeStyle = 'rgba(88,28,135,0.3)'; ctx.lineWidth = 1; ctx.setLineDash([4, 4]);
    ctx.beginPath(); ctx.moveTo(0, y); ctx.lineTo(w, y); ctx.stroke(); ctx.setLineDash([]);
  }
  function render(tSekarang) {
    var f1 = parseFloat(f1Slider.value);
    var f2 = parseFloat(f2Slider.value);
    var t = (tSekarang - waktuMulai) / 1000;
    var fase = t * 2.4;
    ctx.clearRect(0, 0, w, h);
    gambarGaris(atasY);
    gambarGaris(bawahY);
    ctx.strokeStyle = '#2563eb'; ctx.lineWidth = 1.6; ctx.lineCap = 'round';
    ctx.beginPath();
    for (var px = 0; px <= w; px += 3) {
      var y1 = ampAtas * Math.sin((2 * Math.PI * f1 * px) / w - fase);
      var py = atasY - y1;
      if (px === 0) { ctx.moveTo(px, py); } else { ctx.lineTo(px, py); }
    }
    ctx.stroke();
    ctx.strokeStyle = '#f97316'; ctx.lineWidth = 1.6; ctx.lineCap = 'round';
    ctx.beginPath();
    for (var qx = 0; qx <= w; qx += 3) {
      var y2 = ampAtas * Math.sin((2 * Math.PI * f2 * qx) / w - fase);
      var qy = atasY - y2;
      if (qx === 0) { ctx.moveTo(qx, qy); } else { ctx.lineTo(qx, qy); }
    }
    ctx.stroke();
    ctx.strokeStyle = 'rgba(126,34,206,0.35)'; ctx.lineWidth = 1.4; ctx.setLineDash([3, 3]);
    ctx.beginPath();
    for (var ex = 0; ex <= w; ex += 3) {
      var env = Math.abs(2 * Math.cos((Math.PI * (f1 - f2) * ex) / w));
      var ey = bawahY - env * ampBawah;
      if (ex === 0) { ctx.moveTo(ex, ey); } else { ctx.lineTo(ex, ey); }
    }
    ctx.stroke();
    ctx.beginPath();
    for (var fx = 0; fx <= w; fx += 3) {
      var env2 = Math.abs(2 * Math.cos((Math.PI * (f1 - f2) * fx) / w));
      var fy2 = bawahY + env2 * ampBawah;
      if (fx === 0) { ctx.moveTo(fx, fy2); } else { ctx.lineTo(fx, fy2); }
    }
    ctx.stroke();
    ctx.setLineDash([]);
    ctx.strokeStyle = '#7e22ce'; ctx.lineWidth = 3; ctx.lineCap = 'round';
    ctx.beginPath();
    for (var sx = 0; sx <= w; sx += 3) {
      var sum = Math.sin((2 * Math.PI * f1 * sx) / w - fase) + Math.sin((2 * Math.PI * f2 * sx) / w - fase);
      var sy = bawahY - sum * ampBawah;
      if (sx === 0) { ctx.moveTo(sx, sy); } else { ctx.lineTo(sx, sy); }
    }
    ctx.stroke();
    var fb = Math.abs(f1 - f2);
    f1Label.textContent = f1.toFixed(1).replace('.', ',');
    f2Label.textContent = f2.toFixed(1).replace('.', ',');
    fbLabel.textContent = 'fb = |' + f1.toFixed(1).replace('.', ',') + ' − ' + f2.toFixed(1).replace('.', ',') + '| = ' + fb.toFixed(1).replace('.', ',') + ' Hz';
    requestAnimationFrame(render);
  }
  requestAnimationFrame(render);

Perhatikan garis ungu putus-putus (envelope/sampul) yang membungkus gelombang jumlah (tebal) di bagian bawah -- itulah yang menyebabkan bunyi terdengar "menguat lalu melemah" berulang. Coba geser kedua frekuensi sampai hampir sama (misalnya 5 Hz dan 5,5 Hz): envelope-nya akan melebar, berarti pelayangannya melambat. Kalau kedua frekuensinya dibuat SAMA PERSIS, envelope-nya datar -- pelayangan menghilang, tandanya kedua sumber sudah selaras.

## 🧠 Mari Kita Analisis

Sinta bilang: **"Pipa organa yang lebih panjang pasti menghasilkan nada yang lebih TINGGI, karena kolom udaranya lebih besar."**

Menurutmu, apakah pernyataan Sinta ini tepat?

Coba pikirkan dulu sebelum lanjut baca. ...

Pernyataan Sinta **terbalik**. L berbanding LURUS dengan λ (dari L=λ/2 atau λ/4) -- makin panjang pipa, makin BESAR λ. Karena f=v/λ berbanding TERBALIK dengan λ, pipa yang lebih PANJANG justru menghasilkan nada yang lebih RENDAH, bukan lebih tinggi. Inilah sebabnya tuba (panjang) bernada rendah, sedangkan piccolo (pendek) bernada tinggi.

## 🧮 Contoh Soal

### Contoh 1 — Pipa Organa Terbuka

Pipa organa terbuka panjangnya 0,85 m, cepat rambat bunyi 340 m/s. Berapa frekuensi nada dasarnya?

<div class="mtr-formula">λ = 2L = 2×0,85 = 1,7 m<br>f = v/λ = 340/1,7 = 200 Hz</div>

### Contoh 2 — Pipa Organa Tertutup

Pipa organa tertutup panjangnya 0,5 m, cepat rambat bunyi 340 m/s. Berapa frekuensi nada dasarnya?

<div class="mtr-formula">λ = 4L = 4×0,5 = 2 m<br>f = v/λ = 340/2 = 170 Hz</div>

### Contoh 3 — Pelayangan Bunyi

Dua garpu tala berfrekuensi 440 Hz dan 436 Hz dibunyikan bersamaan. Berapa frekuensi pelayangan yang terdengar?

<div class="mtr-formula">fb = |440 − 436| = 4 Hz</div>

## 💡 Coba Pikirkan Lagi

Tadi kamu menebak apa yang menentukan nada sebuah kolom udara. Sekarang setelah belajar, gimana -- jawabanmu masih sama?

Jawaban ilmiahnya: **panjang kolom udara (L)** menentukan λ (lewat L=λ/2 atau λ/4), dan λ bersama cepat rambat bunyi (v) menentukan frekuensi (f=v/λ) -- makin panjang kolom, makin rendah nadanya.

## 🔥 Tantangan HOTS

Sebuah pipa organa tertutup dan sebuah pipa organa terbuka memiliki panjang yang SAMA, yaitu 0,5 m, dengan cepat rambat bunyi 340 m/s. Hitung frekuensi nada dasar masing-masing pipa, lalu jelaskan mengapa hasilnya berbeda.

<div class="mtr-note">
💭 <strong>Petunjuk:</strong> gunakan λ=4L untuk pipa tertutup dan λ=2L untuk pipa terbuka.
</div>

## 🌟 Ringkasan

* 🎺 Pipa terbuka (nada dasar): **λ=2L**. Pipa tertutup (nada dasar): **λ=4L**.
* 🎼 Pelayangan: **fb=|f1−f2|** -- dipakai musisi untuk menyetem alat musik.
* ⚠️ Resonansi bisa bermanfaat (alat musik) maupun berbahaya (struktur bangunan/jembatan).
